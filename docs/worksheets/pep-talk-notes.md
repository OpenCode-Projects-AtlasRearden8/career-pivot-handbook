## Talk 4: My artifact file

I keep this list on my desktop as `proof.txt` (private; no personal data
inside beyond dates and titles). I add one line per finished thing —

```
2026-10-23  wrote first 700-word explainer
2026-10-24  logged 1 skills inventory
2026-10-25  $150 podcast shownotes gig
```

It is both a progress list and, at a glance, an anti-impostor weapon.

## Gentle footnote (always include this with the worksheet)

Pep talks are not a substitute for support. If feelings of being worthless
or hopeless are chronic rather than occasional, that's a health thing
deserving real help — a doctor, a therapist, or a crisis line:
**in the US, 988**; elsewhere, your local line. This handbook is education,
not medical or psychological advice.
